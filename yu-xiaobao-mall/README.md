# 芋小宝商城 Yu Xiaobao Mall

## 项目定位

芋小宝是一款面向年轻女性用户的新中式甜品品牌商城。

核心理念：
- 甜品消费
- 品牌故事
- IP角色互动
- 年轻化社交体验

## 第一阶段功能

- 首页品牌展示
- 商品商城
- 商品详情
- 购物车
- 用户中心
- 芋小宝IP故事
- 限定礼盒
- 会员体系

## 项目结构

```
yu-xiaobao-mall/
├── frontend/  前端商城
├── backend/   后端服务
├── database/  数据库设计
├── design/    UI设计规范
└── docs/      产品文档
```

## Vision

打造一个具有东方甜品美学和年轻女性情感连接的新消费品牌数字空间。
